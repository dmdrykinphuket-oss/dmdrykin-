# Телеграм-бот с Claude

Бот отвечает на сообщения через модель `claude-sonnet-5`, хранит историю по каждому
пользователю (последние 20 сообщений), пускает только разрешённых пользователей и
не падает при ошибках API.

## Установка

```powershell
python -m pip install -r requirements.txt
```

## Настройка

Откройте файл `.env` и впишите три значения:

| Переменная          | Где взять                                                        |
|---------------------|-----------------------------------------------------------------|
| `TELEGRAM_TOKEN`    | Напишите `@BotFather` в Telegram → `/newbot` → скопируйте токен  |
| `ANTHROPIC_API_KEY` | https://console.anthropic.com/ → API Keys → Create Key          |
| `ALLOWED_USERS`     | Ваш Telegram ID — узнать у `@userinfobot`. Несколько — через запятую |

Пример заполненного `.env`:

```
TELEGRAM_TOKEN=8123456789:AAF...пример...xyz
ANTHROPIC_API_KEY=sk-ant-...пример...
ALLOWED_USERS=123456789,987654321
```

Файл `.env` уже добавлен в `.gitignore` — он не попадёт в git.

## Запуск

```powershell
python bot.py
```

Бот работает, пока открыто окно терминала. Остановить — `Ctrl + C`.

## Команды бота

- любое текстовое сообщение — бот отвечает через Claude;
- `/reset` — очистить историю диалога;
- `/start` — приветствие.

Пользователям не из списка `ALLOWED_USERS` бот вежливо отказывает.
